# LookLab AI

A modern React-based AI fashion styling prototype with saved looks and personalized recommendations.

## Project structure

- `src/App.jsx`
- `src/styles.css`
- `src/data.js`
- `src/components/StyleQuiz.jsx`
- `src/components/OutfitCard.jsx`
- `src/components/SavedLooks.jsx`

## Run locally

```bash
cd looklab-ai
npm install
npm run dev
```

Open the local dev URL in your browser to use the app.
